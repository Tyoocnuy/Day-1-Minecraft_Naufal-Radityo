## 📚 A. Rangkuman Materi Day 1 – Git & Github[cite: 1]
Materi berfokus pada pemanfaatan AI melalui Prompt Engineering dan manajemen perubahan kode menggunakan Git dan GitHub[cite: 1]. Pembuatan instruksi AI yang efektif harus memiliki struktur yang mencakup[cite: 1]:
- **Role** (Peran)[cite: 1]
- **Task** (Tugas)[cite: 1]
- **Context** (Konteks)[cite: 1]
- **Format**[cite: 1]

Struktur ini bertujuan agar menghasilkan respons yang relevan, terkontrol, dan minim bias[cite: 1]. Selain itu, dibahas pula alur kerja Git yang mencatat perubahan secara bertahap dari Working Directory, masuk ke Staging Area, hingga disimpan di Repository[cite: 1]. Siklus ini didukung dengan perintah esensial seperti `git init`, `git add`, `git commit`, hingga kolaborasi jarak jauh menggunakan `git push` dan `git pull`[cite: 1].

## 💡 B. Poin Penting Materi Day 1 – Git & Github[cite: 1]
- **Kendali Konteks AI / Prompting**: Penggunaan AI tidak sekadar melempar perintah, melainkan membutuhkan batasan teknis (konteks) yang jelas di dalam prompt agar kode yang dihasilkan tidak berlebihan[cite: 1].
- **Setup Git & Github**: Diberikan step by step lengkap untuk membuat repositori melalui Git dan GitHub[cite: 1].
- **Keuntungan Dari Prompt Engineering**: Keuntungannya dapat meningkatkan performa AI, mengurangi bias dan respon offensive, meningkatkan control dan predictability, dan memberikan pengalaman yang lebih baik[cite: 1].
